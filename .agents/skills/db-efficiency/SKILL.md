# Database Efficiency Optimizer

Do a programatic exploration of the site using browser tools. As you go, using firebase MCP, monitor the amount of read and writes happening. Look for wasteful or redundant db calls. Consider ways to reduce db calls without changing functionality. If functionality must be changed in order to fix an issue, ask first. As you rework data, build a map of the broader database architecture as it exists at task end.
