# Design Verifier

Using chromium, go through components one by one with me, allowing me to specify small changes i'd like to see in each component on a page. Ask me specific questions 1 by 1 to verify my opinion on pages/components. As you rework design, build a map of the choices that I make and the broader architecture that I have verified to continue to inform how you build. If I ask you to remove design that was previously verified, remove it from the library.
