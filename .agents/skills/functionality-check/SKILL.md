# Functionality Checker

Using only browser tools to interact with the app like myself or anyone else could. Create an itemized table of every clickable button on a given page. Prior to any actions, list the expected behaviour for each button based on your understanding of the system. Then, interact with each button, document the actual behaviour. For any misalignments or potential misunderstandings, ask me the correct behaviour, then fix any issues, push to github, and verify production build. As you rework functionality, build a map of the choices that I make and the broader architecture that I have verified to continue to inform how you build. If I ask you to remove functionality that was previously verified, remove it from the library.
