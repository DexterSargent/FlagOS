# UI/UX Audit

Using the browser tool, complete an UI/UX audit of FlagOS. Click around, screenshot things, review the design, search for ways that information could be presented more clear and efficiently. Ensure that the process is repeated in both light and dark mode, on phone, tablet and computer resolution, and from all 4 roles. When finished auditing, fix all identified issues, delete all scripts and screenshots used to audit, then push changes to github and verify that they made it to production. As you rework ui/ux, build a weighted preference list based of the ui/ux choices that I make and the broader architecture that I have verified to continue to inform how you build. If I ask you to remove ui/ux components that were previously verified, remove it from the library.
